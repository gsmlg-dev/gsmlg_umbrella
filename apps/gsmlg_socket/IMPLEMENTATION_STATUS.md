## ⚠️ Known Issue (Not in gsmlg_socket)

### Issue: GSMLG.Telemetry Application Startup
**Location:** `apps/gsmlg_telemetry/lib/gsmlg/telemetry/application.ex`

**Error:**
```
** (ArgumentError) supervisors expect each child to be one of the following:
  * a module
  * a {module, arg} tuple
  * a child specification as a map with at least the :id and :start fields
  * or a tuple with 6 elements generated by Supervisor.Spec (deprecated)

Got: [%{id: GSMLG.Telemetry.Backends.Console, start: {GSMLG.Telemetry.Backends.Console, :start_link, [[...]]}... ]]
```

**Root Cause:** The supervisor children specification is wrapped in an extra list `[[ ]]` instead of a single list `[ ]`.

**Impact:**
- This issue is in the **gsmlg_telemetry** application, NOT in gsmlg_socket
- gsmlg_socket **compiles successfully**
- gsmlg_socket **tests compile successfully**
- Runtime tests fail because gsmlg_telemetry application fails to start

**Fix Required:**
In `apps/gsmlg_telemetry/lib/gsmlg/telemetry/application.ex`, locate the supervisor children definition and ensure it returns a flat list of child specs, not a nested list.

**Example Fix:**
```elixir
# WRONG (nested list)
children = [
  [
    %{id: Backend1, start: {Backend1, :start_link, [[]]}},
    %{id: Backend2, start: {Backend2, :start_link, [[]]}}
  ]
]

# CORRECT (flat list)
children = [
  %{id: Backend1, start: {Backend1, :start_link, [[]]}},
  %{id: Backend2, start: {Backend2, :start_link, [[]]}}
]
```
